# zoi

A software renderer to understand 3D graphics programming.

[Video Showcase](https://youtu.be/jEnuzdkxZaU)

## Features

- From scratch software rasterizer
- Top-left rule to avoid pixel overdraw
- Perspective correct interpolation
- Z-buffer
- 4x MSAA
- Textures + bilinear filtering
- Back-face culling
- Gamma correction + tone mapping
- OBJ parser
- Camera system

## Roadmap

- PBR (Cook-Torrance, Fresnel, NDF)
- Shadow buffer
- Mipmaps
